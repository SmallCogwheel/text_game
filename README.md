# ⚡ ROOT_ACCESS // 기계 도시

사이버펑크 분위기의 텍스트 기반 로그라이크 탐험 게임입니다.
플레이어는 각기 다른 능력을 가진 클래스 중 하나를 선택해 기계 도시 지하를 탐험하고, 최종 제어 코어를 파괴해야 합니다.

---

## 🎮 게임 소개

`ROOT_ACCESS : 기계 도시`는 HTML, CSS, JavaScript만으로 제작된 브라우저 기반 로그라이크 RPG입니다.

플레이어는:

* 맵을 탐험하고
* 몬스터와 전투하며
* 장비를 수집하고
* 층을 올라가며
* 최종 보스를 처치해야 합니다.

사이버펑크 스타일 UI와 레이더 기반 탐험 시스템, 클래스별 특수 능력, 장비 성장 요소를 중심으로 설계되었습니다.

---

# ✨ 주요 특징

## 🧬 클래스 시스템

### 📡 넷러너 (Netrunner)

* 시작부터 레이더 활성화
* 주변 방 정보를 실시간 탐지
* 레이더 단말기 해체 시 엘리트 장비 획득 가능
* 탐색 특화 클래스

### ⚔️ 사무라이 (Samurai)

* 높은 기본 공격력
* `크롬 카타나` 기본 장착
* 공격 시 추가 피해 발생
* 일정 처치 수마다 카타나 강화

### 🛡️ 메카닉 (Mechanic)

* 높은 체력과 방어력
* 장기전에 유리
* 유지력 중심 플레이 가능

---

## 🗺️ 탐험 시스템

* 층마다 맵 크기 증가
* 미니맵 기반 탐험
* 레이더 탐지 시스템
* 휴식 구역 / 보스방 / 엘리트 상자 존재
* 방문 기록 저장

### 맵 아이콘

| 아이콘 | 의미      |
| --- | ------- |
| ■   | 현재 위치   |
| □   | 탐색 완료   |
| ⚠️  | 일반 몬스터  |
| ☠️  | 엘리트 몬스터 |
| 📡  | 레이더 단말기 |
| ⚡   | 휴식 구역   |
| 💎  | 엘리트 금고  |
| ★   | 보스룸     |

---

## ⚔️ 전투 시스템

* 턴제 전투 방식
* 공격 / 도주 선택 가능
* 방어력 피해 감소 시스템
* 엘리트 몬스터 존재
* 층이 올라갈수록 적 강화

### 전투 요소

* 공격력(ATK)
* 방어력(DEF)
* 체력(HP)
* 골드 및 은화 보상
* 클래스 패시브 적용

---

## 🎒 장비 & 인벤토리

장비를 획득하면 능력치가 즉시 적용됩니다.

### 장비 종류

* 일반 장비
* 엘리트 장비
* 은화 전용 상위 장비

### 상승 가능한 능력치

* ATK
* DEF
* HP

### 인벤토리 기능

* 희귀도 정렬
* 공격력 정렬
* 방어력 정렬
* 체력 정렬
* 동일 아이템 수량 통합 표시

---

## 🛒 상점 시스템
