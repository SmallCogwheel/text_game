## [DNA] 클래스 시스템

클래스는 시작 스탯, 시작 장비, 패시브 능력이 모두 다릅니다.

### [NET] 넷러너 (Netrunner)
| 스탯 | 수치 |
|------|------|
| HP | 16 |
| ATK | 4 |
| DEF | 0 |
| SCAN | 3 |

- 게임 시작부터 레이더 활성화 — 인접 방의 내용을 미리 파악
- 레이더 단말기 해체 시 엘리트 장비 획득 (일반 90% / 엘리트 9% / 은화 1%)
- 탐색 및 정보전 특화 클래스

### [SAM] 사무라이 (Samurai)
| 스탯 | 수치 |
|------|------|
| HP | 20 |
| ATK | 7 (+2 카타나) |
| DEF | 0 |
| SCAN | 2 |

- **크롬 카타나** 기본 장착
- 공격 시 가한 데미지의 **20% 추가 피해** 적용
- 몬스터 **4마리 처치마다** 카타나 ATK +2 영구 강화
- 고화력 공격 특화 클래스

### [MEC] 메카닉 (Mechanic)
| 스탯 | 수치 |
|------|------|
| HP | 26 |
| ATK | 3 |
| DEF | 2 (+3 판넬) |
| SCAN | 3 |

- **강화 티타늄 판넬** 기본 장착
- 기계 시체 수색 성공률 **100%** (자폭 트랩 무력화)
- 방어 및 유지력 특화 클래스

### [JST] 광대 (Jester)
| 스탯 | 수치 |
|------|------|
| HP | 18 + 보너스 |
| ATK | 랜덤 |
| DEF | 랜덤 |
| SCAN | 3 |

- **게임 시작 시 ATK / DEF / HP 보너스가 각각 1~5 랜덤 결정**
- 전투에서 공격·방어 대신 **10면체 주사위**를 굴려 운명에 맡김
- 주사위 눈에 따라 데미지·힐·방어가 **player 스탯 기반**으로 동적 계산
- 저주받은 운명 특화 클래스

## [CFG] 난이도 시스템

클래스 선택 전 난이도를 고를 수 있습니다. 난이도는 적의 HP·ATK 배율에만 영향을 줍니다.

| 난이도 | 적 능력치 배율 | 설명 |
|--------|--------------|------|
| 이지 | 50% | 입문자 권장 |
| 노말 | 100% | 기본 난이도 (기본 선택) |
| 하드 | 150% | 숙련자용 |
| 익스퍼트 | 300% | 극한의 도전 |

## [MAP] 탐험 시스템

- 총 **3층** 구성, 층마다 맵 크기 증가 (1층 6×6 → 2층 7×7 → 3층 8×8)
- 미니맵 기반 탐험 — 방을 이동하며 지도 개척
- 레이더 탐지 시스템으로 인접 방 사전 정보 획득 가능
- **층 이동 시 HP 완전 회복**

### 맵 구역 종류

| 아이콘 | 구역 |
|--------|------|
| ■ (초록) | 현재 위치 |
| □ | 탐색 완료 구역 |
| · | 미탐색 구역 |
| [!] | 일반 기계 경비 |
| [X] | 정예 경비 (엘리트) |
| [R] | 레이더 단말기 |
| [+] | 발전 충전소 (휴식/상점) |
| [$] | 엘리트 금고 |
| [B] | 중앙 제어실 (보스) |

## [ATK] 전투 시스템

- 턴제 전투 — 매 턴 **공격 / 가드 / 도주** 선택 (광대는 주사위 / 도주)
- **방어력(DEF)**: 적 공격의 최대 60%까지 피해 감소
- **가드**: DEF +8 일시 적용, 최대 85%까지 피해 감소
- 층이 올라갈수록 몬스터 HP·ATK 스케일 증가
- **정예 몬스터** 처치 시 엘리트 장비 + 은화 보상
- **시체 수색**: 처치 후 전리품 탐색 가능 (자폭 트랩 주의)
