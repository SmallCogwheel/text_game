# ⚙️ 기계 도시 : 작은 톱니 (Machine City : Small Gear)

텍스트 기반의 탐험과 턴제 전투가 결합된 자바스크립트 미니 로그라이크 게임입니다. 플레이어는 6x6 크기의 격자 지도를 탐험하며 아이템과 골드를 수집하고, 자가 발전 충전소와 단말기 레이더를 전략적으로 활용하여 최종 보스인 '중앙 톱니'를 무력화해야 합니다.

---

## 🎮 주요 게임 시스템

### 1. 🗺️ 6x6 확장형 미니맵 & 안개 시스템
* 게임판은 총 6x6 크기의 Grid로 생성됩니다.
* 방문하지 않은 지역은 안개와 어둠(`.`)으로 가려져 있으며, 현재 위치(`■`)에서 상하좌우 1칸 직선거리에 있는 도달 가능한 칸(`□`)만 활성화되어 이동할 수 있습니다.

### 2. 📡 기계 도시 단말기 (레이더) 상시 감지
* 레이더 아이템을 획득하기 전이라도, 지도 어딘가에 숨겨진 레이더 단말기의 위치(📡)가 미니맵에 상시 노출됩니다.
* 플레이어는 게임 시작과 동시에 레이더 방의 위치를 확인하고 동선을 계획할 수 있습니다.
* 레이더 방에 진입하여 장치를 장착하면, 현재 위치 기준 주변 1칸 반경(대각선 포함 8방향)의 안개(`░`)를 실시간으로 스캔하며 숨겨진 보스(★)와 충전소(⚡)의 위치를 미리 밝혀줍니다.

### 3. 🏃 긴급 텔레포트 도망치기 로직
* 몬스터(🤖) 또는 보스(⚙️)와의 전투 중 위험을 감지하면 [🏃 도망치기]를 선택할 수 있습니다.
* 도망칠 경우, 패널티 없이 해당 방에 진입하기 직전에 머물렀던 안전한 방의 좌표로 즉시 텔레포트합니다. 마주쳤던 몬스터는 방에 그대로 남아있으며(`⚠️` 표시), 감소된 체력 상태가 유지되므로 스펙을 강화한 뒤 재도전할 수 있습니다.

### 4. ⚡ 자가 발전 충전소 (고정 휴식처) & 조사 시스템
* 각 방을 조사(searchRoom)할 때마다 최대 3회 제한의 조사 횟수가 차감되며 랜덤하게 스탯 강화 아이템(🛠️)을 획득합니다.
* 지도 상에 고정 배치된 충전소(⚡)에 방문하면 플레이어의 HP가 최대치로 회복될 뿐만 아니라, 소모했던 주변 조사 횟수도 다시 가득(3/3) 충전됩니다.

### 5. 🔄 시스템 재부팅 (완벽한 게임 리셋)
* 전투 중 HP가 0이 되어 사망(SYSTEM FAILURE)하거나, 최종 보스 '중앙 톱니'를 처치하여 게임을 클리어하면 전용 리셋 버튼이 제공됩니다.
* 페이지를 새로고침(F5)하지 않고도 자바스크립트 내부 메모리를 안전하게 비워 플레이어 스탯을 초기화하고, 보스·충전소·레이더방의 위치를 새로운 난수 좌표로 완전히 재배치하여 매번 새로운 게임을 제공합니다.

## 📁 프로젝트 폴더 구조

text
├── index.html              # 게임 화면 레이아웃 및 UI 구조
├── style.css               # 기계 도시 테마 사이버펑크 스타일 시트
├── script.js              # 게임의 핵심 알고리즘, 전투, 맵 렌더링 스크립트
└── assets/                 # 게임에 사용되는 정적 데이터 파일
    ├── boss.json          # 보스 몬스터 정보 (중앙 톱니 스탯)
    ├── items.json          # 조사 시 획득 가능한 장비 장착 아이템 데이터
    └── monsters.json       # 일반 경비 기계 및 로봇 몬스터 데이터

## 🕹️ 실행 방법

1. 프로젝트 내의 모든 파일(`index.html`, `style.css`, `script.js`, `assets/` 폴더)이 동일한 프로젝트 폴더 내에 정상적으로 배치되어 있는지 확인합니다.
2. 비동기 데이터 통신(`fetch API`)을 사용하므로, 브라우저에서 직접 `index.html` 파일을 더블 클릭해 열면 CORS 보안 정책으로 인해 데이터 로드가 제한될 수 있습니다.
3. **VS Code의 Live Server 확장 프로그램**을 이용하거나 로컬 웹 서버 환경을 빌드하여 `http://localhost` 주소 형태로 구동하는 것을 강력히 권장합니다.
4. 만약 로컬 서버 환경 구축이 어려워 파일 로드 오류(404 Not Found)가 발생하더라도, `script.js` 내부의 예외 처리 로직에 의해 게임 자체에 **비상 백업용 더미 데이터가 자동으로 주입**되므로 끊김 없이 정상적으로 플레이하실 수 있습니다.
